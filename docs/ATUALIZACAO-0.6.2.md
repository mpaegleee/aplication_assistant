# Application Assistant 0.6.2

Feche a versão anterior e atualize na mesma instalação. Use a mesma pasta de dados para conservar a senha do aplicativo, as chaves de IA, o currículo, as sessões e as candidaturas. Consulte o [guia de atualização e backup](ATUALIZACAO-0.6.0.md).

## Importar vagas da tela do LinkedIn

1. Em **Navegador e sessões**, escolha LinkedIn. Use **Abrir portal** para entrar pessoalmente no LinkedIn. Se já houver uma sessão válida, use **Abrir busca no navegador interno**.
2. Abra os resultados no Chromium da aplicação. Assuma o controle para pesquisar ou navegar normalmente.
3. Clique em **Importar vagas desta tela**. A aplicação lê os links já carregados, sem abrir cada anúncio. Mostra o total de novas e conhecidas e permite abrir **Ver vagas importadas do LinkedIn**.
4. Se a vaga aparecer como prévia, abra **Abrir vaga no navegador interno**. Com a descrição da vaga carregada, use novamente **Importar vagas desta tela** para completar a prévia. Confira os dados antes de analisar.
5. Use o destino original da vaga para se candidatar. A captura não envia candidaturas.

A captura depende de o LinkedIn carregar a tela dentro do Chromium da aplicação. Uma sessão de outro navegador permanece nele. Se o portal pedir login ou verificação, conclua pessoalmente antes de importar. A prévia sem requisitos não recebe um percentual automático. Respeite as permissões do portal ao coletar os dados.
